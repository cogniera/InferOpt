Stop paying for the same answer twice.

InferOpt finds questions that mean the same thing, keeps the shape of the answer, and only generates the parts that changed. It can cut token usage by up to 90%.

How it works

Embed
Each query is turned into a vector with OpenAI's text-embedding-3-small.
Route
Cosine similarity compares it with known intents. At 0.90 or above, a cached template is used.
Hit
The slot engine fills the template from Redis, or with short, targeted LLM calls for slots it isn't sure about.
Miss
The LLM answers in full, and a reusable template is extracted and stored for next time.
Learn
If the same gap shows up three times, it is promoted to a permanent slot.

Run it

You need Docker and an OpenAI API key. It opens at localhost.

git clone https://github.com/cogniera/InferOpt.git
cd InferOpt
echo "OPENAI_API_KEY=your-key" > api/.env
docker compose up --build
