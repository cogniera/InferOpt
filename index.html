InferOpt

CodeDevpost

InferOpt makes LLM answers cheaper. When a question means the same as one it has seen, it reuses the shape of that answer and only generates what changed. This can cut token use by up to 90%*.

    Pipeline

    Embed
    Each question is turned into a vector with OpenAI text-embedding-3-small.
    Route
    Cosine similarity compares it with known intents. A score of 0.90 or more uses a cached template.
    Hit
    The template is filled from Redis. Short LLM calls fill only the slots it is unsure of.
    Miss
    The LLM answers in full. A reusable template is extracted and stored for next time.
    Learn
    A gap that appears three times becomes a permanent slot.

    Setup

    You need Docker and an OpenAI API key. The app opens on localhost.

    git clone https://github.com/cogniera/InferOpt.git
cd InferOpt
echo "OPENAI_API_KEY=your-key" > api/.env
docker compose up --build

    Stack

    FastAPI, Redis, OpenAI embeddings, Express, React, Tailwind and Docker.

    * An upper bound for very repetitive questions, as measured by the project. Results vary with the workload.
